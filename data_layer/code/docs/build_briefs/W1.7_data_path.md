## Deliverables

### M15: bus encoder and clock domains
- CIR → MIL-STD-1553B messages:
  - BC schedule (minor frame 50 Hz, major 12.5 Hz per the dictionary rate groups);
  - RT/SA addressing; status and BIT words;
  - AS15532-style scaling from the dictionary (AD-39).
- ARINC-429 labels with SSM.
- **Each LRU on its own oscillator** with offset Δ, a per-unit parameter (`core.time.ClockDomain`). The BC polls asynchronously.
- Duplicates and skips come from schedule mismatch, with no slip sentinels on digital words.
- The six timestamps (§8): `t_bus` = LRU latency + the wait for the next poll.

### M16: recorder writer and download
- **One IRIG 106 Ch10/11 file per sortie:**
  - TMATS first (from the dictionary generator);
  - recording events;
  - analog, discrete, 1553 and time packets;
  - **cumulative packet sequence counting** (AD-38: the 8-bit sequence wraps; the `record_id` uses the cumulative count).
- **Separate sinks (AD-25):** CDR continuous loop, ECMS log, HUMS DAU, OAC maintenance log, FTI (test only).
- **Download simulator:** per-sortie batch with realistic delay → `t_ingest`, and occasional duplicate or partial downloads (`DUPLICATE_DOWNLOAD`).

### M17: ground decoder
- Ch10 (synthetic or real) → `param.samples` with `provenance = full_path`, in the **identical contract schema**. Validate with `load_contract("v0").validate`.
- Handles duplicates, skips, skews, clock drift, sentinels and validity.
- `record_id` per AD-38 full-path rules.
- Recorder and decoder quality flags.
- **Open semantic question you must resolve and report:** what `t_sample` means on the full path. It could be the true acquisition instant, or what a decoder can know (an LRU timestamp if transmitted, else derived from `t_bus` minus nominal latency). Propose, with evidence, and flag `DECODER_INTERPOLATED` / `CLOCK_SUSPECT` as appropriate.

## Acceptance

| ID | Criterion |
|---|---|
| A1 | Encode/decode round trip within quantisation, for every dictionary channel on a bus |
| A2 | Bus loading ≤50 %; duplicate, skip and skew statistics match the clock model; slip-window period = 1/(f·Δ) |
| A3 | `.c10` conformance vs the public sample file; independent parsers agree: pyChapter10 plus a second, independent reader (write a minimal one from the standard if `irig106lib` is unavailable, and say so) |
| A4 | CIR → Ch10 → decode equals CIR within quantisation |
| A5 | **Identical schema on fast and full paths:** both batches validate against the same Arrow schema; a cross-path test |
| A6 | Re-download produces no duplicates through `ParquetStore` / `ReplayStreamer` |
| A7 | Real sample Ch10 files decode. Use public samples only, never restricted sources; if none is available offline, say so |
| A8 | Deterministic bytes: the same inputs give an identical `.c10` and identical decoded Parquet |
