## Deliverables

### M02 — scenario, fleet calendar, missions (event-driven)

**Six-layer generator** (AD-28):
1. flying-task calendar;
2. sortie: mission mix, duration, configuration, base, ambient;
3. phase grammar;
4. semi-Markov manoeuvre primitives inside envelope, fuel and AB budgets;
5. latent pilot traits;
6. hand-off as `scenario.sortie_plan` events.

**Also:**
- Owns `scenario.epoch_utc_ns` (AD-38).
- Accepts M21 order effects: programme changes, tail swaps, usage restrictions. Provide the API; W1.8 calls it.
- Usage-mode output is sortie summaries (durations, phase times, AB time, cycles), so usage mode can run without physics.
- Proxy mode replays recorded inputs. Provide a replay adapter interface that takes `FlightRecord`-like input arrays.

**Evidence anchors** (each a parameter with tags):
- sortie lognormal, median ≈45–55 min, P5–P95 ≈25–90 min;
- 1–2 sorties per aircraft per flying day in peace, 4–6 in surge;
- night ≈10–20 %;
- IMD weather-cancel probabilities.

### M03 — environment and process disturbances
- USSA-76/ISA, MIL-HDBK-310 extremes, base climatology for Indian bases.
- ERA5 replay: interface plus a small adapter. No large download; use a synthetic fixture in tests.
- von Kármán turbulence for production, Dryden for tests; 1−cos gusts; log-profile shear.
- **AD-32 per-unit disturbance streams:**
  - `env.w_engine` (e, 4), `env.w_bleed_pto` (e,), `env.w_hyd` (h,);
  - state-space shaping filters, each the sum of an aircraft-common and a unit-specific component;
  - configurable PSD and cross-unit coherence;
  - keyed `(scenario, tail, serial, sortie)`; CRN across forks.
  - Parameters are tagged placeholders with sweeps. W2.4 identifies them on proxy data.

### M04 — pilot and guidance
- Deterministic guidance tracks plan targets.
- Crossover-model stochastic overlay with per-pilot traits.
- Outputs: inceptors, PLA per engine, discretes.
- Proxy hooks: `pilot.at_engage` / `pilot.at_n1_cmd`, passed through from replay.
