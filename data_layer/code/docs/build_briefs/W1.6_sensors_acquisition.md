## Deliverables

### M12: sensor physics, sensor dynamics, installation bias
Per sensor class:
- T5 averaging harness: 2 × 4 probes, open-probe exclusion, shorted probe reads low;
- N1 eddy-current blade counting; N2 alternator frequency;
- pressure transducers; LVDT/RVDT; RTD with de-icing;
- air data:
  - vane 2nd order (fₙ ≈0.11–0.21 Hz per m/s EAS, ζ ≈0.04–0.10);
  - upwash; boom bending;
  - position error with the transonic jump;
  - pneumatic lag (×4.3 at 40 kft);
  - TAT recovery and heater error;
- capacitance gauging; flowmeter type.

Sensor dynamics:
- FF meter first-order lag;
- thermocouple τ ∝ W^-0.5 (AGARD);
- meter update intervals.

Installation bias and aging from `health.sensor_bias`. **Sensor-fault modes** come from M11 events (`W1_interfaces.md` M11).

### M13: acquisition
- **Double quantiser:** native step, then recorder lattice, from dictionary fields; saturation.
- **Independent idiosyncratic noise:** AR(1) allowed, with regime multipliers and a heavy-tail mixture. **At or below the measured idiosyncratic level** (noise ceiling, W0.5 finding).
- **Artefacts:**
  - glitch words;
  - validity gating;
  - deadband and episodic freeze;
  - sentinels in place of NaN; never NaN.

  Analog paths lose samples in slip windows (the clock model in `core.time.ClockDomain`), with no independent dropout process (AD-06). Digital words have no slip sentinels.
- SI → EU conversion (AD-38).
- Output: **CIR** (`CIR_SCHEMA`; `sample_index`, `rng_key_path`, acquisition-stage quality flags).

**Forbidden here:** any coupled multivariate dynamics (AD-04). An AD-29 coupled-discrepancy fallback, if ever enabled, is not in W1.

### Helpers on main
- `Dictionary.si_to_eu` / `eu_to_si` / `eu_conversion` (exact conversions, %N1/%N2 via `channel_reference`).
- `phalanx.ground.cir.cir_from_streams` + `StreamSamples` (CIR from per-stream arrays, explicit counts, truth mask).
- `truth_at_samples`: AD-35 interpolation of 240 Hz truth at LRU ticks. `t_true` defaults to `t_sample` (A-W0.4-21).
- `core.sampling.sample_ports` / `samples_for_steps`: variable samples per truth step, never NaN.
- `FastPathConfig.from_dictionary`: rejects channels not in the dictionary and flags out-of-range values.

Use these; don't re-implement them.

### In-loop path (`W1_interfaces.md` §3)
The same kernels produce the controller lane values at the DFCC/FADEC clock domains. **Lane ports carry the SI value of the digitised reading** (quantise in EU, then `eu_to_si`). Bind them as `lane.<channel_id>`. A6 compares `eu_to_si(CIR value)` with the lane value, bitwise. The recorded CIR value at an
acquisition instant equals what the controller saw: same kernel, same draw index. Expose both entry points.
