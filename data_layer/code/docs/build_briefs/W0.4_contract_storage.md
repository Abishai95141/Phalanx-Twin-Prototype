## Deliverables

### 1. Contract spec v0 as data
YAML or JSON under `src/phalanx/dictionary/contract/spec/v0/`. Every §12 topic:
- `param.samples`;
- `events.bit_faults`, `events.exceedances`, `events.cautions`;
- `usage.counters`;
- `sortie.manifest`;
- `maint.records`;
- `orders.status`, plus the order record itself (§11.1);
- `labels.truth` (**restricted**; marked so in metadata).

**Fields, types and nullability** exactly per §12, including:
- the six time fields as int64 ns (`t_true` only in CIR and labels);
- the `validity` enum;
- the `quality_flags` bit set, with stable bit positions;
- `provenance`, `record_id`, `dict_version`, `dict_hash`.

For records (§10) and events: derive the field lists from §10/§12, and grep the report for NAMP/S5000F fields. Mark derived choices as tagged assumptions.

### 2. Generators: spec → artefacts
- `pyarrow.Schema` per topic, with field metadata (units, `time_unit=ns`, enum tables, restricted flag).
- JSON-Schema for manifests and orders.
- An Avro schema generated from Arrow (for the v1.x Kafka adapter): just the generator and a round-trip test; no Kafka.
- Deterministic generation, with a **contract version (semver) and a contract hash**.
- **Public API:** `load_contract(version) -> Contract` with `.schemas[topic]`, `.version`, `.hash`, enum and flag tables.

### 3. CIR (`ground/cir.py`)
The internal record the observation layer (M13/M14) hands to the data path:
- per-sample value;
- `t_true` and `t_sample`;
- truth value (restricted);
- validity and flags;
- `source_lru`, lane, `param_id`;
- `rng_key_path` reference.

Columnar (Arrow / struct-of-arrays), not per-sample Python objects.

### 4. `record_id`
- Deterministic hash of (tail, sortie, channel ID, packet sequence/counter, message index) per §12.
- Stable byte encoding; blake2b; fixed width. **Never builtin `hash()`.**
- For the fast path, define the "packet sequence / message index" equivalent deterministically from CIR order, and document it.

### 5. Fast-path adapter
- CIR → `param.samples` records (`provenance = direct`).
- Time fields the fast path can't know (`t_bus`, `t_record`): define the rule (e.g. null, or a documented latency model).
- The adapter takes `dict_version`/`dict_hash` and a `param_id → units` map as arguments; it is wired to M01 at integration (W0.X).
- **Schema must be identical to what the full path will emit (AD-12).** Validate every batch against the generated schema.

### 6. Storage (`streaming/`)
- **Parquet writer:** partitioned by date / tail / sortie.
  - Deterministic file bytes: fixed row-group size, fixed compression, no wall-clock metadata. Check whether pyarrow writes `created_by` or timestamps, and neutralise or document them.
- **Reader:** reads by sortie, tail and time window.

### 7. Replay streamer
- Emits records in event-time order with per-sortie watermarks.
- Deterministic tie-breaking.
- **Idempotent on `record_id`:** re-ingesting duplicates (e.g. `DUPLICATE_DOWNLOAD`) yields no duplicates downstream.
- **Information discipline hook:** `as_of(t)` returns only records with `t_ingest ≤ t` (I5). This is what the orders interface will use.

### 8. Toy end-to-end test
A small synthetic CIR batch (constructed in the test) → fast path → Parquet → replay. Outputs must be bitwise
stable across runs.

## Acceptance (map each to named tests)

| ID | Criterion |
|---|---|
| A1 | Every §12 topic and field present, with the right types and nullability (a test enumerates §12) |
| A2 | Schema generation deterministic; contract hash stable; a spec edit changes the hash |
| A3 | Arrow ↔ Parquet ↔ Arrow round-trip lossless; Parquet bytes identical across two writes |
| A4 | `record_id` deterministic and collision-free on a property-test corpus; stable golden values |
| A5 | Replay: event-time order; per-sortie watermarks; replay output bitwise identical to the files; duplicates suppressed |
| A6 | `as_of(t)` never returns a record with `t_ingest > t` (property test) |
| A7 | Fast-path batches validate against the generated schema; a malformed batch is rejected (negative test) |
| A8 | Avro schema generated from Arrow; round-trip a record through Avro if a pure-Python Avro lib is installed, else validate structurally and report |
| A9 | `make check` green |
