# W1.3a: F404-IN20 engine truth model (M07): CLM steady state and stochastic dynamic shell

**Critical path.** This module carries the project's central realism requirement. Round 2 showed that a
deterministic, open-loop, input-driven engine model over-couples engines and spools and inverts the small-signal
FF→N2 lag. **M07 must be a stochastic state-space system** that runs in closed loop with M08 (W1.3b) and is driven by
M03 process disturbances (AD-04, AD-31, AD-32).

## Deliverables

### 1. Component models, steady state (CLM)
- 0-D component-level model of a two-spool, mixed-flow, afterburning turbofan.
- Scaled maps for fan, HPC, HPT and LPT, as tables in `params/M07/` with provenance.
- Combustor, mixer, AB, nozzle, and humid-air thermodynamics.
- Design point closed to IN20 ratings [DIRECT]: 84 kN class, 70 kg/s, OPR ≈28, 1,072 kg.
- IN20 closure values as tagged ASSUMPTION with sweeps: FPR 4.3–4.4, BPR 0.27–0.30, CPR 6.4–6.5, T4 ≈1,770–1,790 K.
- -400 cycle table [TRANSFER] for off-design shape.
- Health inputs: `health.engine` (10 component deltas, `W1_interfaces.md` M10).

### 2. Dynamic shell, as a stochastic state-space model
- Rotor ODEs: I_HP ≈3, I_LP ≈3.5 kg·m², tuned.
- Inter-component volume dynamics.
- Metal temperature and tip-clearance states.
- AB light-off state machine; surge/stall model.
- **Process disturbances `env.w_engine` enter the dynamics**: fuel metering, combustor efficiency, inlet recovery, shaft load. They never enter the outputs.
- Steady state = equilibrium of the dynamic model. This is a test.
- The model is vectorised over `n_engines`.

### 3. Corrected-parameter outputs
- θ, δ corrections on all outputs (`eng.*` ports per `W1_interfaces.md`).

### 4. Kernels and identification readiness
- Numba kernels, a NumPy reference, and **complex-step safety** throughout. Calibration (AD-34) uses complex-step Jacobians.
- Expose a **transient-window simulation API** for W2.3/W2.4 identification: given inputs and initial state over a window, return outputs.
- Expose a residual function with **transient weighting**: detected accel/decel steps are weighted separately from steady levels (AD-34).

### 5. Not in W1
The PWL/LPV usage-mode surrogate is built in W2.3, from the calibrated CLM. Expose what W2.3 needs: steady-state
sweeps and a linearisation API.
