# W2.4a: Proxy mode (DASHlink Tail 687), identification, and the first behaviour quick look

**Goal.** Get the **first real behavioural evidence**. The build's own engine-side chain is put in the DASHlink proxy configuration:
- the M07 `separate_fixed` topology, 4 engines (AD-43);
- M08 governing plus the autothrottle loop;
- M03 disturbances, including `fan_face` (AD-46);
- M12/M13 configured to DASHlink texture.

It is driven by **recorded real inputs** (PLA, ALT, MACH, TAT, A/T state), identified on 687-CAL, and compared with real data using the B1–B6 battery. This WP is **development only**. The archive-2 gate is W2.4b and runs once, later, after its own pre-registration.

## Staging (after E1; binding)

E1 found that the AD-46 reachability test passes only under a direct-Wf fixture governor, which AD-50 rejects.
- Under the real M08 law with everything wired, every disturbance mix that brought r(N1,N2) to ≤ 0.55 drove
  r(N1,FF) negative (−0.40…−0.73) and B2 to ≥ 0. The joint target was not reached (n=24 runs).
- N1–EGT came out ≈ 0, against a real value of +0.56.
- That study had **no A/T loop and no proxy texture**.

W2.4a therefore runs in two stages.

**W2.4a-1: build and reachability (this agent first).**
1. Deliverables 1–3 below: `separate_fixed`, the proxy configuration with the A/T outer loop, and the drivers.
2. **U3, multi-engine lanes.** M08 expects lane buffers of shape (cap, e), but M12/M13 lanes are (1,) with no
   engine axis. Give M12/M13 a per-engine lane path for e > 1. The Tejas e = 1 path must stay bitwise unchanged.
3. **U4, replay producers.** In proxy mode nothing produces `af.mach` (consumed by M07 and M12), `af.tas`/`af.alt`
   (M12) or `scenario.phase` (M13). Add replay producers fed from the DASHlink inputs, so that the hardened
   conformance gate (E1-MF) passes with no hand-wiring.

   reachable by the proxy chain:

   - **Statistics,** computed with the M20 battery estimators on the **textured recorded output**, not truth:
     - B1 fast: N1–N2, N1–FF, N2–FF, N1–EGT, and cross-engine N1/N2/EGT;
     - B2 lags: FF→N2, FF→N1, N2→N1, FF→EGT.
