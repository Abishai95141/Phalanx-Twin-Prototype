# W2.2: Observation and data-path integration (M12–M17 on the truth loop) — skeleton milestone

**Goal.** Turn the integrated truth loop (W2.1) into the data a real fleet would produce, on **both paths**:
- **fast path:** sensors → acquisition → CIR → contract;
- **full path:** sensors → acquisition → bus → Ch10 recorder → ground decoder → contract.

The two paths must give an identical schema.

**Skeleton milestone (plan §5):** one tail and one sortie, end to end to the contract on both paths. Replay is
deterministic, and a fork from a mid-sortie snapshot continues bitwise.

**Owned paths:**
- `src/phalanx/sensors/avionics/` (new);

  integration only);
- `src/phalanx/integration/datapath.py` (new; W2.1 owns the rest of `integration/`);
- `tests/*/test_w22_*.py`;
- the W2.2 section of `docs/assumptions.md`.

Contract changes follow AD-41: an additive 0.2.0 with a version bump, a migration note and a decision-register

## Phases

**Phase A starts in parallel with W2.1.** It needs no integrated loop and uses replayed or recorded truth traces.
Put new code in new files, with minimal hooks in shared ones. W2.1 edits the M12/M13 FADEC/DFCC lane path for the
fused kernel, so do not edit those parts.

1. **Avionics computed outputs (AD-42 open item; decided as AD-51).** Add an M12 avionics sensor-system extension
   at "just enough" (P3) fidelity:
   - INS/GPS and AHRS error models;
   - ADC computation from the probe and vane sensors, including the undercarriage-dependent air-data error (report
     l.157);
   - radar altimeter;
   - SMS status.

   CWS stays in M14, and OAC logs go to M14/M18. Error models carry evidence tags (TRANSFER/ASSUMPTION with
   sweeps). Include the **electrical → navigation-invalid-without-flag** coupling (report l.741) as a physical
   path from `util.bus_v`.
2. **U6: channel coverage plan.** Every one of the 464 dictionary channels gets exactly one owner class:
   - an M12 sensor;
   - a `RECORDED` LRU-computed producer;
   - another contract topic (`usage.counters`, `events.*`, `maint.records`, …);
   - or **explicitly not simulated**, with its contract state from `not_measured_states.csv`.

   Write it as machine-readable data and enforce it with a test: 100 % classified, and no channel silently
   absent. Close the named gaps with an owner and a plan: ECS, `BRK.PRESS`, HYD level, `ENG.FUEL_INLET_T`, SPS/JFS,
   and the AD-42 signals not yet bound by M12 (`af.hag`, `util.brake_p`, `util.hyd_res_level`,
   `util.probe_heat`, `util.fuel_inlet_t`).
3. **Dictionary 0.1.2 migrations on the data path:**

   - M15/M17 → the dictionary code-word layout;
   - M13 → `converter_step` with noise in EU.
