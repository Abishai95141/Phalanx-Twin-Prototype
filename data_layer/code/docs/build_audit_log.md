# Build audit log

Append-only record of build events. The coordinator is the only writer; entries are never edited or deleted (a
correction is a new entry that references the old one).

**Event types:**

| Event | Meaning |
|---|---|
| APPROVAL | Owner decision |
| DECISION | Coordinator decision, or a decision-register change |
| ENV | Toolchain or environment change |
| BRIEF | Agent brief issued (file in `docs/build_briefs/`) |
| LAUNCH / REPORT | Agent started / reported back |
| REVIEW | Coordinator diff review, with findings |
| TEST | Test or check run, with the command, n and the result |
| MERGE | Branch merged to `main` |
| GATE | Wave exit gate result |
| CONFLICT | Disagreement between sources, or between an agent and the spec |
| DEVIATION | Departure from the plan or the spec, with the reason |
| INCIDENT | Something that went wrong, and the fix |
